LVS - Lite Visual Style

Version: 1.0.0

Minecraft shaderpack for Iris + Sodium.
Target: Minecraft 1.21.8.

LVS is a Chocapic13 V9 shader edit with original lighting, atmosphere, sun shafts, color grading, water animation and plant wind work layered on top.

Distribution name required by the Chocapic13 license:
LVS - Lite Visual Style (Chocapic13' Shaders edit)

This is the first stable release of LVS.

The experimental biome-fog system is not included in the stable feature set because it was too expensive for the desired performance target.

Main features:
- soft lighting and improved sky/ground bounce
- warmer artificial light and golden-hour lighting
- cool moonlight
- sun shafts
- cinematic color grading
- TAA / FXAA options and existing depth-of-field controls
- animated water
- stronger wind for grass, tall plants and leaves
- dedicated gentle movement for vines and hanging roots
- synchronized plant movement in shadow rendering
